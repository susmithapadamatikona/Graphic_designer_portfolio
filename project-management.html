EDITORIAL REVIEW

Keep the project list purposeful.

A small, clear collection is easier to explore.

01

Title

Use a concise project name with consistent capitalization.

02

Category

Choose the discipline that best describes the work.

03

Year

Use the actual project year rather than the date of the latest edit.

PUBLICATION STATES

Draft first. Publish when ready.

The portfolio only shows records marked Published.

01

Draft

Use draft status while refining the description and metadata.

02

Published

Make the record available in portfolio listings and detail pages.

03

Unpublished

Return a project to draft without deleting its record.

BEFORE DELETING

Consider the project’s place in the collection.

Deletion removes a record from this browser’s portfolio data.

01

Review the entry

Check that you have selected the intended project.

02

Consider a draft

Unpublish the project if you want to retain it for later.

03

Check the listing

After saving, preview the portfolio and its filters.
