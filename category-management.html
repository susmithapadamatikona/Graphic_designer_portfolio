A CLEAR TAXONOMY

Group work by useful distinctions.

Categories should help visitors find a relevant discipline.

01

Be specific

Choose recognizable service names rather than internal labels.

02

Avoid duplicates

Keep singular, plural and differently cased names from splitting the same group.

03

Stay concise

Short labels work better in filter controls.

CHANGING A CATEGORY

Keep assigned work connected.

Renaming a category also updates the projects using that name.

01

Review assignments

Check how many projects use the category before changing it.

02

Rename carefully

Use the Rename action to preserve the association.

03

Reassign before deletion

A category with assigned projects must be emptied before it can be deleted.
